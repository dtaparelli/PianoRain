PianoRain uses source time 0–26.5 seconds, preserving leading silence and speed.
The final 0.5 seconds fade linearly to silence. Ogg Vorbis was decoded to stereo
44.1 kHz PCM16 WAV. No normalization or musical time shift was applied.

The accompanying notes.mid is an approximate transcription generated locally
with the original float32 Note_pedal ONNX model, not a captured MIDI performance
or a verified score. Preparation uses stereo averaging, scipy resample_poly
(44.1 kHz → 16 kHz), PCM16 precision, ten-second windows with 50% overlap and
reference quarter/three-quarter stitching. Note/pedal events clip to 26.5 s.
MIDI export uses 384 PPQ and 500000 microseconds per quarter note.
